# Projeto 2 — Sistema de Gestão de Academia

Este repositório contém a primeira etapa do projeto acadêmico de gestão de uma academia. A especificação, o design e o protótipo estão organizados na pasta [`projeto2/`](projeto2/).

## O que foi feito nesta etapa

- Definido o problema, os usuários, as regras de negócio e os critérios de aceite.
- Elaborada uma proposta de arquitetura, modelo ER, rotas da API e ADR para a execução do CRUD.
- Criado um protótipo web estático para alunos, planos, documentos e relatórios.
- Registrado o uso de IA e as decisões ainda pendentes.

O front-end ainda é um protótipo: sem a API configurada, usa dados demonstrativos locais e não grava no RDS ou no S3. A infraestrutura AWS e o backend serão desenvolvidos nas próximas etapas.
